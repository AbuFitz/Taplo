# Social platform glyphs

The shared renderer, registration picker and portal use individual glyphs from the installed Simple Icons 16.35.0 package. LinkedIn is the unchanged path from [Simple Icons 13.0.0](https://github.com/simple-icons/simple-icons/blob/13.0.0/icons/linkedin.svg), retrieved 24 October 2026, retained locally because the current set no longer includes it. [Original CC0 licence](SIMPLE-ICONS-CC0.md). No package downgrade or additional icon library.

Platform marks identify the destination of an owner-supplied profile link. They do not imply endorsement or integration. Shapes remain unchanged; colour follows the page's foreground for consistent legibility.
