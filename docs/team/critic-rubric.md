# Visual critic rubric

Scored 1-5 per row by an independent reviewer who sees only screenshots and the reference set. 5 = would sit beside the references without apology. A screen passes at **no row below 4 and an average of 4.3+**. Anything below 4 comes back with a specific fix, never a general note.

| Row | 5 looks like | 1 looks like |
| --- | --- | --- |
| First five seconds | One obvious thing to do; the result appears fast | A form first, value later |
| Hierarchy | One focal point, three type sizes at most | Everything the same weight |
| Space and rhythm | Generous, consistent spacing on one scale | Cramped or uneven, boxes crowding |
| Type | One confident display face, readable body, no tiny text | Many sizes, small grey text |
| Colour and contrast | A few deliberate colours, every label readable | Muddy, low contrast, or arbitrary accents |
| Imagery and illustration | Professional, one coherent style, adds meaning | Clip-art, placeholder, or decoration |
| Motion | Explains or confirms, never decorates | None, or distracting |
| Copy | Short, plain, human, no filler | Instructional, repeated, jargon |
| Information capture | Asks only what the next screen needs, when it is useful | Asks for things before it gives value |
| Polish | Aligned, crisp, no clipped or overlapping content | Misaligned, clipped, inconsistent radius or weight |

Reviewer rules: compare against `.claude/refs/`; name the exact element for every score under 5; never praise to be kind; list the three highest-impact fixes first.
