# Taplo design team

Role skills live in `.claude/skills/taplo-*`. Start with `taplo-design-team`, which routes a change through strategy, research, architecture, specialist passes, system check, build, growth review and verification.

Each feature keeps its decisions in `docs/team/<feature>/` (brief, research, spec, motion, review) so choices can be audited.

Connected tools (verified this session): Figma (file "Taplo design system", https://www.figma.com/design/IJjCbpKBGmqmxgcN7UIwGu, foundations page with platform colour, spacing, radius and the twelve looks), LottieFiles (search and download public animations), Framer, Supabase, Lovable.

Limits: After Effects, Jitter, Spline, the Rive editor, real devices and live accounts are not available in the cloud sandbox. Figma starter plan: one variable mode per collection, so looks are stored as named variables. Skills produce briefs, storyboards and code-based implementations and name what a person with those tools still has to do.
