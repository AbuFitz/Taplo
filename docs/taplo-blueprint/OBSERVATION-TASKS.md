# Independent observation tasks

Edition 1.0 · Ready-to-use research plan; no real sessions have been conducted as part of this pack.

| Participant / scenario | Task without coaching | Observe / verify |
| --- | --- | --- |
| New owner without artwork | Create correct identity, first offer and useful page | Missing-image path, price/request meaning, publish understanding |
| Barber shop owner | Invite practitioner and front desk with different access | Can explain own/all calendar, contact visibility, refund/export boundaries |
| Practitioner | Find today’s work, request time off, edit own profile draft | Needs no owner-wide settings; understands approval and affected appointment |
| Customer from staff social link | Book that professional at the correct shop | Seller identity, staff selection retained, no silent substitution |
| Parent/customer | Book two learners on a group lesson | Payer versus learner, seat count, joining information, privacy |
| Mobile-service customer | Request eligible work and understand arrival/price scope | Coverage versus time, deposit versus later quote, address purpose |
| Retail customer | Choose variant and collection; handle last-unit conflict | Price/stock truth, preserved input, understandable next action |
| Workshop organiser/customer | Sell out then promote a two-seat waitlist request | Queue/quantity/expiry fairness; no charge just for waitlist |
| Returning customer | Find a booking/order and ask for a change | Activity navigation, policy impact, right conversation |
| Finance/support role | Resolve uncertain payment without duplicate charge | Permission and provider truth; exact customer wording |
| Departing member/owner | Remove access or close merchant with work pending | Future work, data ownership, public link, domain/NFC/pass continuity |
| Accessible/mixed-device use | Complete relevant task with keyboard/text enlargement and theme change | Focus, hierarchy, retained state, readable content |

For each session record consent/appropriate privacy arrangements, participant context, device, task/script revision, attempted path, outcome, assistance, misunderstanding, timing where useful and participant words. Do not invent quotes or replace an observation with a persona. Success criteria are set before the session and relate to correct task outcome, not praise of the design. Recruit appropriate adults/participants and safeguards for any research involving children; do not casually expose real child/client data.

Pre-session checks: use internally consistent example records, current expected behaviour, working prototype paths, no unavailable actions disguised as complete, and a neutral facilitator. Classify findings as unsafe/wrong outcome, blocked task, repeated confusion, recoverable friction or visual preference. Fix structural findings even if inconvenient. The goal is fewer preventable surprises, not a promise of only cosmetic feedback.
