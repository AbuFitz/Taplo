## The database decision, without salesmanship

Neither Neon nor Supabase is configured, per founder clarification. Keep Neon Postgres as the current working greenfield selection because the proposed server-owned engine and recovery/branch economics fit it. Current Supabase is a valid integrated alternative; current Neon also has broader backend services. Neon is not objectively always cheaper/better and no migration saving is assumed. Comparable real capacity and engineering/operations effort still need measurement. A conditional “sign us up if better” is not treated as a completed account opening or a reason to purchase before selecting actual entity/account configuration.

## Optional purchases and exclusions

| Item | Proposed treatment |
| --- | --- |
| UK SMS | Same service all plans: £9/100 units or £39/500; unit is provider-billed segment; auto top-up off |
| Card processing | Merchant pays actual provider fees; no proposed Taplo transaction commission |
| Domain | Connection included Core+; registration/renewal/transfer deliberately priced per actual registrar/TLD |
| NFC accessories | Separate product, shipping/replacement/returns and stable-link promise |
| Reward value | Merchant funds its actual discounts/free items/services; not subsidised by Taplo subscription |
| Business above 3 locations | No price or unsupported promise invented; separately assess scope before offering |
| WhatsApp / external-shop sync / public headless | Not standard launch inclusions; no silent extra bill |
| Custom work | No bespoke development entitlement hidden in the software price |

A Core owner using no SMS can use the software for £12. Buying 100 units gives an initial £21 bill; 600 units gives £60 with the proposed packs. Long/Unicode content can consume more than one unit; do not conceal SMS-heavy total cost in a cheap base price. Existing paid units/allowance/cancellation treatment follows reviewed account/exit terms.
