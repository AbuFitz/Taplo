# Category operating contracts

Thirteen profiles share common records and equivalent section structure. Typed configuration records contain exact fields. Category labels/icons adapt the experience; capability/legal readiness controls real enablement. Food/clinical/vehicle-sale and native digital scopes remain gated as specified, not silently sold as supported.

## Barber, hair & beauty

Terminology: services / professionals / appointments. Icon: Phosphor scissors.

**Fields:** common Business/Location/Offer plus the named typed configuration records; public/private projection and claim provenance required. Configurations: ServiceConfig, FulfilmentConfig.

**Availability:** professional + chair/equipment; total conservative occupancy; no processing-time overlap baseline.

**Team:** practitioner own assigned customer/work; reception location scheduling; owner publishes staff gallery.

**Checkout:** named staff price/duration visible before slot; any-staff only eligible resources.

**Daily work:** Today prioritises actual accepted commitments and relevant next actions; work state, money state and fulfilment/attendance separate; action scope from authoritative role/assignment.

**Cancellation/refund:** AssessCancellation binds immutable accepted policy/current money; clear merchant/customer initiator; automatic unambiguous outcomes only, disputed/statutory branch review; no blanket forfeiture.

**Exceptions:** named-worker absence; add-on extends resource time; shared chair race; late arrival.

**Scope gate:** consumer/source policy review; patch-test/health intake only reviewed necessary scope.
