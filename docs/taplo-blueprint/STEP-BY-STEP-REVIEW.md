This is a review order, not a rule to defer essential engine/security work until screens are finished. Define dependent rules in parallel within the blueprint, then validate each visible journey against them. Keep a single decision log and a cross-impact list so a visual change does not silently break another surface.

For now, the first review is the mobile page plus product popup and bag. It is an interaction concept for evaluation. It is not a claim that the live application has been changed, all workflows implemented, or the final visual system approved.
